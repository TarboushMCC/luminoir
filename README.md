# Luminoir

A luxury fragrance brand website concept — dark, editorial, and product-as-hero.

> **Note:** This repository currently contains documentation only. The source code will be published at a later date. Concept/passion project — not affiliated with a real business.

## Experience

- Loading screen, custom cursor, and scroll progress indicator
- Hero with an animated perfume-bottle centerpiece
- Collection, best-sellers, and campaign sections
- Brand story and "fragrance experience" narrative sections
- Testimonials and newsletter capture

## Tech stack

| Layer | Choice |
|---|---|
| Framework | Next.js 14 (App Router) |
| Language | TypeScript |
| Styling | Tailwind CSS |
| Animation | Framer Motion |
| Icons | Lucide |
